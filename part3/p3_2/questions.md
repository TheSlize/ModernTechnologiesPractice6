# Вопросы по Hibernate - Часть 3

## Вопрос 1: JDBC vs Hibernate

**Вопрос:** В чем разница между JDBC и Hibernate?

**Ваш ответ:**

JDBC — низкоуровневый API, требует ручного написания SQL и маппинга ResultSet в объекты. Hibernate — ORM-фреймворк, который автоматически маппит таблицы на Java-классы, сам генерирует SQL и управляет транзакциями.

---

## Вопрос 2: HQL vs SQL

**Вопрос:** Что такое HQL и чем он отличается от SQL?

**Ваш ответ:**

HQL (Hibernate Query Language) работает с Java-сущностями и их полями, а не с таблицами и колонками БД. Это делает запросы независимыми от конкретной СУБД.

---

## Вопрос 3: Аннотации Hibernate

**Вопрос:** Какие основные аннотации Hibernate используются на сущности Movie?

**Ваш ответ:**

Основные аннотации: @Entity (класс — сущность), @Table(name = "movies") (имя таблицы), @Id (первичный ключ), @GeneratedValue(strategy = GenerationType.IDENTITY) (автоинкремент), @Column (маппинг поля на колонку).

## Вопрос 4: Что будет без @Column(nullable = false)?

**Вопрос:** Что произойдёт если убрать `@Column(nullable = false)` — на уровне кода или базы данных?

**Ваш ответ:**

На уровне кода ничего не изменится — Java позволит присвоить полю `null`. На уровне базы данных при `hbm2ddl.auto=create` Hibernate сгенерирует столбец без ограничения `NOT NULL`, то есть в таблицу можно будет вставить запись с пустым `title`. Ограничение `nullable = false` работает только при автоматической генерации схемы Hibernate — если схема уже создана вручную, аннотация на неё не влияет.
